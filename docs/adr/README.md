# Architecture decision records

One file per decision that is expensive to reverse. Each says what was decided, why, what it costs, and what was rejected. To change a decision, write a new ADR that replaces the old one (change its status to "Replaced by ADR-00NN"); never rewrite history. Changes go through a `[spec-change]` (START-HERE, Step 9).

Format: **Status** · **Context** · **Decision** · **Consequences** · **Rejected alternatives**.
