At the end of M2 a user can add a supplier, record a fixed-rate purchase paid in cash, and see the khata and trial balance. Show it to the client (T2.10).

## T2.1 App shell, brand, formatting helpers

**Goal:** the app looks like ZB Poultry Protein Mill and every number is formatted one way.

**Client requirement:** spec §15, §15.7; D-34 (later), O-17, O-18.

**Depends on:** T1.10.

**Build exactly:**
- Brand per `docs/brand.md`: Tailwind `@theme` tokens, shadcn `--primary` and `--ring` set to `brand-green` in light and dark themes. The IBM Plex Sans font is already self-hosted since T0.1; check numbers use `tabular-nums`.
- Login page: `brand/zb-logo-256.png` copied to `public/images/zb-logo-256.png`, shown above the form at max 120 px wide, on white (white tile in dark mode).
- Sidebar header: monogram (`public/favicon.svg`) 32 px + text "ZB Poultry Protein Mill".
- Sidebar groups exactly as spec §15.1. Navigation config lives in `resources/js/lib/navigation.ts` as data: `{ group, label, href, permission, mobileFirst }`, where `href` comes from a **Wayfinder** route import (never a hard-coded URL; there is no Ziggy `route()`). Each later task adds its own items when its route exists; this task adds Dashboard only. An item is shown only when the user has the permission; a group with no visible item is hidden. Mobile bottom bar: New purchase, New sale, New payment, Quick expense (added by their tasks, same visibility rule).
- Staging banner: when the shared prop `app.env_name` is `staging`, a yellow bar at the top of every page with the glossary "Staging banner" text.
- Shared Inertia props per conventions §10.
- `resources/js/lib/format.ts` (pure string functions, no `parseFloat`/`Number` on values):
  - `formatMoney(value: string, opts: { numberFormat: 'lakh'|'international', amountRounding: 'whole_rupee'|'two_decimals' }): string` → `Rs 1,00,000` (whole_rupee) or `Rs 1,00,000.00` (two_decimals); negative values shown with a leading minus only where the caller allows it (trial balance never needs it).
  - `formatKg(value: string, decimals: number): string` → `2,800 kg` (grouping follows number format).
  - `formatRate(value: string, decimals: number): string` → `Rs 52.50`.
  - `formatDate(ymd: string, format: 'd-m-Y'|'d M Y'): string` → `05-01-2026` or `05 Jan 2026`.
- `resources/js/lib/money.ts`: `multiplyToPaisa(kg: string, rate: string): string` using `BigInt` on scaled integers, for the live total preview only.
- Components in `resources/js/components/app/`: `StatusBadge` (all badges of spec §15.3, glossary words), `BalanceInWords` (props `words`, `amount`, `pendingKg?`), `MoneyText`, `KgText`.
- Front-end unit tests run with the kit's toolchain: add the script `"test": "vp test"` to `package.json` (vite-plus bundles Vitest; install nothing). Test files sit next to the code as `*.test.ts`.

**Rules:** spec §15.1–§15.3, §15.7; BR-RPT-04, BR-RPT-05.

**Tests (write first, `npm test`):**
- `formatMoney('100000.00', lakh, two_decimals)` → `Rs 1,00,000.00`
- `formatMoney('100000.00', international, two_decimals)` → `Rs 100,000.00`
- `formatMoney('12345678.50', lakh, two_decimals)` → `Rs 1,23,45,678.50`
- `formatMoney('999.00', lakh, whole_rupee)` → `Rs 999`
- `formatMoney('0.00', lakh, two_decimals)` → `Rs 0.00`
