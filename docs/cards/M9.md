## T9.2 Speed

**Goal:** the laptop and the server answer quickly; NFR-02 holds on the developer's laptop.

**Build exactly:** Inertia SSR off (servers never build an SSR bundle; with the Vite dev server it rendered every full page load through Vite). `composer run dev` runs `serve --no-reload` and `.env.example` sets `PHP_CLI_SERVER_WORKERS=4`. `Ageing::overdueMany` and `Ageing::averageDaysToPayMany`: the oldest-first figures (§12.6) for many buyers in one PostgreSQL query each (numeric; the final division in `Decimal`), used by the overdue-buyers alert, pending balances and business insights; insights supplier balances in one `partyNets()` query. `zb:time-pages` times the 3-month statement PDF. Timings before and after, on the same machine, in `docs/release-checks.md`.

**Not in this task:** lazy loading of the signed-in layout (it would add a request to every signed-in first page to save 1 request on the cached login page).

**Tests:** `AgeingOverdueManyTest` (newest-first rule against the existing match on 3,000 random histories; both SQL functions against `overdueFor()` and `averageDaysToPay()` on AT-2 and on a random history posted through the Actions). T-12 and AT-1 to AT-6 unchanged.

**Done when:** tests pass; every page in `zb:time-pages` under 3 seconds on the measured machine, recorded.
